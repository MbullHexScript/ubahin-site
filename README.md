
# Ubahin Website

Website resmi Ubahin, aplikasi konversi file desktop untuk Windows.

**Beda format? Ubahin aja.**

Website menyediakan informasi produk, format yang didukung,
panduan penggunaan, unduhan, FAQ, catatan rilis, dan privasi.

Website tidak menyediakan layanan konversi online.
Seluruh proses konversi dilakukan melalui aplikasi desktop.


## Privacy

- Tidak ada akun pengguna.
- Tidak ada unggahan file melalui website.
- Konversi berjalan secara lokal pada aplikasi desktop.
- Preferensi tema website disimpan pada browser.
- Website tidak membutuhkan backend maupun database.
