Ubahin 1.0.0 untuk Windows 11 x64.

Unduh Ubahin 53,87 MiB

Installer .exe • Gratis digunakan dan dibagikan

Sebelum memasang
Memerlukan Microsoft Edge WebView2. Jika belum tersedia, pemasangan runtime memerlukan internet. Konversi sesudahnya tetap lokal.

Informasi keamanan Windows
Installer belum ditandatangani. Windows mungkin menampilkan peringatan atau memblokirnya. Jangan menonaktifkan perlindungan Windows.

Lihat checksum SHA-256
Alternatif pemasangan melalui npm

Untuk pengguna Node.js 22.19–22.x. Unduh paket bridge npm dan installer di atas ke folder yang sama, lalu jalankan dari folder itu: 

npm install -g ./ubahin-desktop-installer-1.0.0.tgz
ubahin-install --installer ./Ubahin-1.0.0-Setup-x64.exe

Bridge memverifikasi installer dan membuka wizard Windows. Konversi tetap melalui GUI. Belum ada paket registry publik. Menghapus paket npm tidak menghapus aplikasi desktop.

Lisensi & sumber komponen pihak ketiga

Ubahin gratis dipakai dan dibagikan; kode asli aplikasi tetap privat. Hak komponen pihak ketiga mengikuti lisensinya sendiri.

  • Izin penggunaan Ubahin
  • Notices komponen pihak ketiga
  • Petunjuk sumber dan rebuild
  • Sumber komponen pihak ketiga (2 bagian, total 2,13 GiB)

Kamu cukup mengunduh installer untuk memakai Ubahin. Jika membagikannya kembali, sediakan juga izin, notices, checksum, dan tautan arsip sumber di halaman rilis yang sama. Petunjuk penyatuan arsip sumber disertakan pada rilis.

Hal kecil sebelum mulai.

Apakah file saya dikirim ke internet?

Tidak. Aplikasi desktop mengonversi file secara lokal, tanpa akun dan tanpa unggahan. Internet mungkin diperlukan saat memasang WebView2 yang belum tersedia.

Apakah bisa mengubah semua format?

Belum. Format dan codec yang didukung tercantum di bagian Format. File terenkripsi, macro Office, format lama DOC/XLS/PPT, dan beberapa isi dokumen aktif ditolak. Ubahin memberi alasan ketika file tidak dapat diproses.

Bagaimana dengan Windows 10 dan ARM?

Rilis pertama diuji untuk Windows 11 x64. Windows 10 dan ARM64 belum diklaim teruji atau didukung.

Bagaimana memperbarui atau menghapus aplikasi?

Pasang pembaruan dari installer baru yang dibagikan pengembang. Belum ada update otomatis. Untuk menghapus, buka Pengaturan Windows → Aplikasi → Ubahin. Simpan hasil konversi di folder milikmu dan perhatikan pilihan hapus data di wizard.

Ada file yang gagal dikonversi?

Catat versi Ubahin, langkah kejadian, format, dan pesan kesalahannya saat melapor ke pengembang di komunitas tempat kamu mendapatkan aplikasi. Gunakan file contoh sintetis, bukan dokumen pribadi.

Catatan rilis

1.0.0

Rilis pertama

File berbeda, alur yang sama.

Konversi gambar, ikon, PDF, audio dan video. Antrean campuran, cancel/retry, riwayat lokal, tema terang/gelap, serta Office ke PDF melalui LibreOffice opsional.

Dukungan awal Windows 11 x64. Installer unsigned. Pembaruan berikutnya akan mengikuti masukan pengguna.

Privasi yang sederhana.

Aplikasi menyimpan preferensi dan riwayat minimal secara lokal, maksimal 50 batch. Menghapus riwayat tidak menghapus hasil. Folder dan profil Windows tidak dienkripsi oleh Ubahin.
